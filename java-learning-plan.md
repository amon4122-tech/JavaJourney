## Организация

### Время

| Период | Часы | Фокус |
|--------|------|--------|
| **Будни (Пн–Пт)** | **3 ч/день** | чтение + практика |
| **Суббота** | **4–5 ч** | крупный кусок мини-проекта недели |
| **Воскресенье** | **3–4 ч** | повтор, рефакторинг, без тяжёлой новой темы |

**Итого:** ~22–26 ч/неделю. Базовый блок: **6–8 недель**.

### Ритм буднего дня (3 ч)

| Блок | Время | Действие |
|------|--------|----------|
| Разогрев | 15 мин | Повтор: переписать вчерашний фрагмент или объяснить вслух |
| Теория | 25–35 мин | Один § Хорстманна + 5–10 строк в `notes.md` |
| Код | ~2 ч | IntelliJ: разминки + шаг в `PersonalAssistant` |
| Закрепление | 20–30 мин | Экзаменационная задача или Debug |

**Правило:** к концу будня проект в рабочем состоянии. Git — с недели 2 (желательно коммит каждый будний день).

### Ритм выходных

- **Суббота:** довести мини-проект недели до состояния «можно показать».
- **Воскресенье:** переписать ключевой фрагмент с нуля, повтор `notes.md`, без новой большой темы после 2-го часа.

## Формат работы с тьютором (ИИ)

### Запрос плана (перед практикой)

```
Неделя 1, день 2 (вторник)
Подсказки: A
```

Коротко: `Д2` / `Н1 Вт` — тоже понятно.

### Вечерний отчёт

```
День N — отчёт
Читал: гл. …, § …
Сделано: … / не успел: …
Вопрос: …
Код: (фрагмент или «пришлю»)
Подсказки: A / B / C / D
```

### Уровни подсказок

| Уровень | Что получаешь |
|---------|----------------|
| **A** | Только формулировка задачи |
| **B** | Намёк, псевдокод |
| **C** | Разбор твоего кода |
| **D** | Полное решение (по явной просьбе) |

### Что выдаёт тьютор на каждый день

1. Что читать (§ Хорстманна)
2. 2–3 разминки
3. Шаг в `PersonalAssistant`
4. Одна «экзаменационная» задача
5. Критерий «готово»
