Отличия main () Java от C
1. C это глобальная функция, а в Java живет в классе
2. С - возвращает значение, т.к она int main() (0 если все ок, либо код ошибки), в Java ничего не возращает
т.к. она по умолчанию void main()
3. В С при обявлении main не применяются модификаторы, в то время как в Java
применяются модификаторы доступа (public), вызова метода без создания копии (static)

Вот самое главное в три строчки:

* **Сходство:** Оба языка создают массивы фиксированного размера из элементов одного типа с доступом по индексам от `0`.
* **В C:** Массив — это небезопасный «голый» указатель на память, который содержит мусор при создании и не знает своей длины.
* **В Java:** Массив — это безопасный объект в куче, который автоматически зануляется, знает свою длину (`.length`) и защищен от выхода за границы.

Класс = структура данных + поведение.
В отличие от struct в C, класс объединяет данные и функции для их обработки (методы) в один объект, а также поддерживает 
инкапсуляцию, наследование и полиморфизм. Структура в C — это просто пассивный набор данных.
---
Task[] — размер фиксирован;
ArrayList<Task> — размер растёт (add, get, size).
---
Struct в C — набор полей; поведение отдельно. Поля часто меняют напрямую.
Класс в Java — поля + методы в одном типе; с private снаружи меняют только через методы.
---
ArrayList — это упорядоченный список, где элементы ищутся по их порядковому номеру (индексу 0, 1, 2...). 
Подходит для хранения однотипных объектов, где важна последовательность (как наш список задач).

HashMap — это ассоциативный словарь, где данные хранятся парами Ключ -> Значение. 
Порядок хранения не гарантирован, но поиск по ключу происходит мгновенно (за O(1)), 
независимо от того, три элемента в карте или миллион. Применяется, когда нужно связать уникальный идентификатор с объектом.
